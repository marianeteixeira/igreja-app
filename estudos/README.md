# Estudos — IgrejaApp

## Sobre

Esta pasta reúne o planejamento, os registros de aprendizagem e os materiais complementares desenvolvidos durante os estudos de Backend .NET e SQL Server.

O aprendizado é aplicado ao **IgrejaApp**, projeto prático de administração de organizações religiosas, com foco em modelagem de dados, desenvolvimento backend, segurança e organização de código.

## Plano de estudos

**Duração:** 24 semanas  
**Carga horária:** 3 horas semanais  
**Organização:** 3 sessões de 1 hora por semana

Cada semana segue, preferencialmente, a seguinte divisão:

| Dia | Atividade |
|---|---|
| 01 | Estudo teórico e documentação |
| 02 | Implementação prática |
| 03 | Testes, revisão e versionamento |

**[Consultar plano de estudos completo](./plano-de-estudos.pdf)**

## Tecnologias

- C# e .NET

## Padrão de documentação

Cada sessão poderá conter:

1. Objetivo da aula.
2. Conceitos e tecnologias estudados.
3. Exercícios e atividades realizadas.
4. Decisões técnicas e regras de negócio.
5. Dificuldades e pendências.
6. Próximos passos.

Os registros devem distinguir atividades planejadas de atividades efetivamente concluídas.

## Diretrizes

- Priorizar a compreensão dos conceitos antes da implementação.
- Manter o escopo alinhado ao planejamento de estudos.
- Documentar decisões técnicas e alterações relevantes.
- Versionar os scripts e demais artefatos desenvolvidos.
- Utilizar exclusivamente dados fictícios durante o desenvolvimento inicial.
- Tratar requisitos futuros separadamente das funcionalidades implementadas.

## Objetivo final

Consolidar conhecimentos em desenvolvimento backend com .NET e SQL Server por meio da construção progressiva de uma aplicação, mantendo um histórico técnico das decisões, implementações e aprendizados ao longo do projeto.
